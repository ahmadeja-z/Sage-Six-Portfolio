1. APPROVED BRAND DIRECTION

The attached website design is the primary reference for layout, composition, typography, spacing, and visual treatment. The supplied new Sage Six logo is the source of truth for brand colours and geometry.

This direction replaces the previous charcoal-and-muted-sage theme throughout the website.

Follow:

* Clean white and soft off-white backgrounds.
* Deep navy headings, navigation, and primary buttons.
* Cyan, teal, blue, indigo, and purple accents derived from the new logo.
* Bold modern sans-serif headings and highly readable supporting text.
* Generous whitespace, precise alignment, subtle borders, and restrained shadows.
* Hexagonal and triangular geometry inspired by the logo.
* A premium, welcoming, confident software-company identity.

Sample the actual logo colours when implementation begins and establish reusable colour tokens. Treat colours estimated from screenshots as provisional.

Preserve the logo’s exact proportions, facet arrangement, orientation, and wordmark. Do not redraw or reinterpret it with generative AI.

Follow the selected reference’s hero orientation and hierarchy. On smaller screens, adapt the composition thoughtfully while preserving its identity.

2. THIS IS A COMPLETE WEBSITE REDESIGN

Apply the new design system to every existing page and shared component, including:

* Homepage.
* Services and expertise pages.
* Work listing and project cards.
* Every case-study page.
* About/company pages.
* Insights listings and articles.
* Contact forms and calls to action.
* Navigation, footer, menus, buttons, cards, and modals.
* Loading, empty, error, and 404 states.
* Existing AI-assistant interface.
* Social-sharing graphics and browser branding where appropriate.

Audit the actual website first when implementation is authorised. Avoid leaving sections in the old theme.

Preserve existing functionality, working integrations, URLs, SEO metadata, project links, and factual content unless a change is necessary and documented.

4. MOTION IS A CORE PART OF THE EXPERIENCE

Create a cohesive, animation-rich experience that feels elegant, responsive, and purposeful.

Plan:

* A carefully sequenced hero entrance.
* Subtle staggered reveals for the hexagonal service panels.
* Smooth navigation and menu transitions.
* Refined button, link, and project-card hover states.
* Gentle image movement within fixed containers.
* Scroll-triggered section reveals.
* Clear form focus, validation, and success feedback.
* Tasteful page transitions that preserve navigation behaviour.

Use motion to guide attention and explain interactions. Make important moments expressive while keeping reading areas calm.

Suggested starting values:

* Hover feedback: 150–250 ms.
* Section entrances: 400–700 ms.
* Stagger delays: 60–100 ms.
* Entrance movement: approximately 12–24 px.

Avoid scroll hijacking, constant spinning, distracting loops, excessive parallax, custom-cursor dependence, and long loading introductions.

Respect reduced-motion preferences. Keep content accessible without animation, provide keyboard-visible focus states, and ensure mobile users receive equivalent interactions.

5. QUALITY REQUIREMENTS FOR LATER IMPLEMENTATION

The finished website must:

* Work beautifully on mobile, tablet, and desktop.
* Preserve readable contrast and clear navigation.
* Show complete screenshots wherever understanding the interface matters.
* Avoid unintended image cropping, stretched assets, and layout shifts.
* Open newly visited pages at the top while respecting sensible back-navigation restoration.
* Load efficiently using appropriately sized, compressed images.
* Keep essential content and controls usable while animations run.
* Feel consistent from the homepage through the deepest case study.

When I authorise implementation, inspect the existing project, create the shared design system, produce the required assets, implement the redesign, and verify the important pages and interactions.
